موقع مكتب محمد السرجاني
========================

المشروع صفحة واحدة متجاوبة مع الموبايل، بألوان أزرق وأبيض.

التشغيل:
- افتح index.html في المتصفح لمعاينة الموقع.
- ارفع محتويات المجلد إلى GitHub Pages أو استضافة المواقع التي تستخدمها.

إضافة شعار المكتب:
- ضع صورة الشعار الأصلية داخل مجلد assets.
- سمّ الملف office-logo.png
- لا تحتاج إلى تعديل أي كود؛ سيظهر الشعار أعلى الصفحة تلقائياً.

ملاحظات:
- زر واتساب يفتح محادثة الرقم 01006906248.
- زر إنستاباي ينسخ رقم الموبايل حتى يستخدمه العميل داخل التطبيق.
- رابط فودافون كاش يستخدم صيغة اتصال بالكود المدخل، وقد لا تدعمها كل الهواتف أو إصدارات تطبيق الاتصال؛ يمكن تعديل آلية التحويل بعد اختبارها على الهاتف المستهدف.
- لا يمكن إنشاء QR نهائي قبل معرفة رابط الموقع بعد نشره.
